# 行人速率分析工具 (Person Speed Analyzer)

基于 **YOLOv8 + 多目标追踪** 的行人速率分析工具，支持视频文件和摄像头实时两种模式，实时检测行人、追踪运动轨迹并估算真实世界速度（m/s），分析结束后自动生成速度报告与速度变化曲线图。

## 功能特性

- **行人检测**：使用 YOLOv8n 模型检测画面中的行人（仅 person 类别，置信度过滤）
- **多目标追踪**：IoU + 匈牙利算法进行检测框与轨迹的数据关联，支持目标短暂丢失后重匹配
- **速率估算**：基于像素位移 + 比例尺换算为真实世界速度（m/s）
  - 自动模式：按行人检测框高度估算比例尺（假设身高 1.7m）
  - 手动模式：自定义 m/px 比例尺
- **实时可视化**：追踪框颜色随速度变化（慢→绿，快→红），绘制运动轨迹线，实时显示 ID 与速度
- **分析报告**：结束后输出每个行人的平均速度、帧数、时长的表格报告 + matplotlib 速度曲线图
- **测试视频生成**：可生成含干扰物（树干状矩形、模糊人影、块状物体）的测试视频，用于验证抗误检能力

## 环境要求

- Python 3.8+
- Windows / macOS / Linux
- 摄像头模式需要可用的摄像头设备

## 安装

```bash
pip install ultralytics opencv-python matplotlib scipy numpy
```

> 首次运行时会自动加载项目目录下的 `yolov8n.pt` 模型权重。

## 使用方法

### 方式一：图形界面（推荐）

双击 `启动行人速率分析.bat`（Windows），或运行：

```bash
python video_speed_gui.py
```

- 选择 **视频文件** 模式并浏览选择 `.mp4/.avi/.mov/.mkv` 文件，或切换 **摄像头** 模式（编号 0 为默认摄像头）
- 选择比例尺模式（自动 / 手动 m/px）
- 点击 **开始分析**，实时窗口中按 `Q` 或 `ESC` 可随时停止
- 分析结束后自动弹出速度报告（控制台表格）和速度曲线图

也可以在启动时直接传入视频路径：

```bash
python video_speed_gui.py path/to/video.mp4
```

### 方式二：录制摄像头测试视频

```bash
python record_test.py
```

从摄像头录制 10 秒测试视频并保存为 `test_video.mp4`，录制时在摄像头前走动即可。

### 方式三：生成含干扰物的测试视频

```bash
python generate_noisy_video.py
```

在 `test_video.mp4` 基础上叠加树干、模糊人影、背包状干扰物，生成 `test_video_with_noise.mp4`，用于测试追踪器的抗误检能力。

## 技术原理

1. **检测**：YOLOv8n 逐帧推理，过滤出 person 类别且置信度 ≥ 0.5 的检测框
2. **数据关联**：计算已有轨迹与检测框的 IoU，构建代价矩阵后用匈牙利算法求最优匹配（IoU > 0.3 视为匹配成功）；未匹配的检测框创建新轨迹，连续丢失超过 30 帧的轨迹被清除
3. **速度计算**：取轨迹最近 15 帧的首尾质心像素距离，除以时间差得到像素速度，再乘以比例尺换算为 m/s：
   - 手动模式：直接使用设定的 m/px 比例尺
   - 自动模式：`scale = 1.70m / 行人框高度px`（假设行人身高 1.7m）

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `fps` | 视频实际帧率 | 用于速度计算的时间基准 |
| `history_frames` | 15 | 速度计算的滑动窗口帧数 |
| `max_lost` | 30 | 轨迹最大丢失帧数，超过则删除 |
| `conf_threshold` | 0.5 | YOLO 检测置信度阈值 |
| `scale_mode` | auto | 比例尺模式：`auto` / `manual` |
| `manual_scale` | 0.02 | 手动比例尺（米/像素） |

## 注意事项

- 自动比例尺基于「行人身高 1.7m」的假设，透视变化较大的场景建议使用手动比例尺并现场标定
- 速度为平面估算值，未做相机标定与透视矫正，结果仅供趋势参考
- 摄像头模式下未匹配到帧率时按 15fps 处理
